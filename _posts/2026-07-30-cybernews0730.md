## Password Resets Alone Can No Longer Stop Modern Identity Attacks
<span class="badge badge-primary" style="font-size: 0.7rem;">Authentication</span>
Security experts are warning that changing a compromised password is no longer enough to fully remove attackers from an affected account. Modern threat actors increasingly steal session cookies, authentication tokens, and persistent credentials that allow them to maintain access even after a password reset. As a result, incident response teams must also revoke active sessions, invalidate tokens, and review authentication logs for suspicious activity. Researchers recommend adopting phishing-resistant authentication methods such as passkeys and hardware security keys alongside continuous identity monitoring. The shift highlights how identity-based attacks have evolved well beyond simple password theft.

## Critical OpenWrt DHCPv6 Vulnerability Enables Remote Code Execution
<span class="badge badge-primary" style="font-size: 0.7rem;">Vulnerability</span>
Researchers have disclosed a critical vulnerability in OpenWrt's DHCPv6 implementation that could allow remote attackers to execute arbitrary code on vulnerable routers. Because OpenWrt powers a wide range of consumer and enterprise networking devices, successful exploitation could provide attackers with control over critical network infrastructure. Developers have released security updates and are urging administrators to patch affected systems as quickly as possible. Security experts note that internet-facing routers remain attractive targets because they often serve as gateways into internal networks. Prompt patching is considered essential to prevent exploitation.

## CertiGhost Flaw Targets Microsoft Active Directory Certificate Services
<span class="badge badge-primary" style="font-size: 0.7rem;">Vulnerability</span>
Researchers have disclosed a newly named attack technique called CertiGhost that affects Microsoft Active Directory Certificate Services environments. The vulnerability could allow attackers to abuse certificate-based authentication mechanisms to impersonate legitimate users or elevate privileges under certain conditions. Because enterprise environments rely heavily on digital certificates for secure authentication, the issue represents a significant risk if left unaddressed. Organizations are advised to review certificate templates, audit Active Directory Certificate Services configurations, and implement recommended mitigations. The research underscores the growing importance of protecting identity infrastructure beyond traditional passwords.
