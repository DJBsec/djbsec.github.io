Password Resets Alone Can No Longer Stop Modern Identity Attacks

Authentication Security experts are warning that changing a compromised password is no longer enough to fully remove attackers from an affected account. Modern threat actors increasingly steal session cookies, authentication tokens, and persistent credentials that allow them to maintain access even after a password reset. As a result, incident response teams must also revoke active sessions, invalidate tokens, and review authentication logs for suspicious activity. Researchers recommend adopting phishing-resistant authentication methods such as passkeys and hardware security keys alongside continuous identity monitoring. The shift highlights how identity-based attacks have evolved well beyond simple password theft. Read More

Critical OpenWrt DHCPv6 Vulnerability Enables Remote Code Execution

Vulnerability Researchers have disclosed a critical vulnerability in OpenWrt’s DHCPv6 implementation that could allow remote attackers to execute arbitrary code on vulnerable routers. Because OpenWrt powers a wide range of consumer and enterprise networking devices, successful exploitation could provide attackers with control over critical network infrastructure. Developers have released security updates and are urging administrators to patch affected systems as quickly as possible. Security experts note that internet-facing routers remain attractive targets because they often serve as gateways into internal networks. Prompt patching is considered essential to prevent exploitation. Read More

Apple Releases iOS 26.6 With Important Security Fixes

Vulnerability Apple has released iOS 26.6, addressing multiple security vulnerabilities affecting supported iPhone devices. The update includes fixes for issues that could potentially allow privilege escalation, information disclosure, or arbitrary code execution if exploited. Apple is encouraging users to install the update promptly to ensure they receive the latest protections. While there is no indication that every flaw was actively exploited, timely patching remains one of the most effective security practices. The release continues Apple’s regular effort to strengthen the security of its mobile ecosystem. Read More

ShinyHunters Claims Ernst & Young Breach and Threatens Data Leak

Data Breach The ShinyHunters cybercrime group has claimed responsibility for breaching systems associated with Ernst & Young and has threatened to publish allegedly stolen information. At the time of reporting, the claims were still being investigated, and the full scope of any potential compromise had not been independently confirmed. If validated, the incident could expose sensitive corporate or client information while adding another major organization to the group’s list of alleged victims. Investigators are continuing to assess the authenticity of the claims and determine whether any customer data was affected. The situation demonstrates how extortion groups continue using public leak threats to pressure organizations during incident response. Read More

CertiGhost Flaw Targets Microsoft Active Directory Certificate Services

Vulnerability Researchers have disclosed a newly named attack technique called CertiGhost that affects Microsoft Active Directory Certificate Services environments. The vulnerability could allow attackers to abuse certificate-based authentication mechanisms to impersonate legitimate users or elevate privileges under certain conditions. Because enterprise environments rely heavily on digital certificates for secure authentication, the issue represents a significant risk if left unaddressed. Organizations are advised to review certificate templates, audit Active Directory Certificate Services configurations, and implement recommended mitigations. The research underscores the growing importance of protecting identity infrastructure beyond traditional passwords. Read More

Chrome Extension Helps Prevent Sensitive Data Exposure in AI Chats

Privacy Researchers have introduced a Chrome extension designed to monitor conversations with AI assistants and alert users when sensitive information may be shared. The tool analyzes prompts before they are submitted, helping identify confidential business data, credentials, or personal information that should not be exposed to external AI services. As organizations increasingly integrate generative AI into daily workflows, preventing accidental data leakage has become an important security objective. The extension complements existing data loss prevention strategies by providing real-time guidance to users. It reflects growing awareness of privacy risks associated with enterprise AI adoption. Researchers Identify Cryptographic Weaknesses in Claude Mythos

Vulnerability Security researchers have identified cryptographic implementation weaknesses affecting the Claude Mythos framework that could reduce the effectiveness of certain security protections. The findings focus on implementation issues rather than flaws in the underlying cryptographic algorithms themselves. Developers are encouraged to review affected components and apply recommended updates or configuration changes to strengthen security. Experts emphasize that even strong encryption can become vulnerable if implemented incorrectly. The research serves as a reminder that secure software engineering practices remain just as important as selecting robust cryptographic algorithms. Read More

Dysphoria Botnet Uses Blockchain Domains to Conceal Command Servers

Malware Researchers have found that the Dysphoria botnet is using blockchain-based domain services to hide its command-and-control infrastructure from traditional detection methods. By relying on decentralized naming systems, the malware operators make it significantly more difficult for defenders to seize or disrupt their infrastructure. The approach demonstrates how cybercriminals continue adopting emerging technologies to improve the resilience of their malware operations. Security teams are encouraged to strengthen network monitoring and identify unusual outbound communications that may indicate botnet activity. The findings highlight the continued evolution of modern botnet architecture. Read More

Fortinet Unveils Unified FortiGate Firewall and SASE Platform

Threat Intelligence Fortinet has announced a new FortiGate platform that combines next-generation firewall capabilities with Secure Access Service Edge, or SASE, functionality. The unified platform is designed to simplify security management while providing consistent protection for branch offices, remote workers, cloud environments, and corporate networks. According to Fortinet, the integrated approach reduces operational complexity while improving visibility across distributed enterprise environments. Industry analysts view the announcement as part of the broader convergence of networking and cybersecurity technologies. The release reflects increasing demand for centralized security architectures that support hybrid work. Read More

OpenAI Releases Codex Security CLI as Open Source

Threat Intelligence OpenAI has open-sourced its Codex Security CLI, providing developers and security professionals with an AI-assisted command-line tool for secure software development workflows. The utility supports tasks such as code review, vulnerability identification, and security automation while allowing organizations to inspect and customize the source code. By making the project open source, OpenAI aims to encourage transparency, community collaboration, and broader adoption of AI-powered security tooling. Security researchers believe the tool could accelerate secure coding practices and improve vulnerability remediation efforts. The release reflects the growing role of open AI technologies in modern cybersecurity operations. Read More
